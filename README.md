# Sobremesa: slow, regional Spain

A static travel website for slow, regional travel in Spain: food, small towns, rail journeys and festivals. It's plain HTML, CSS and a little JavaScript, generated by one small Node script with **no dependencies**.

## Run it

You need Node 18 or newer.

```bash
npm run dev      # build into ./dist and serve at http://localhost:4321
npm run build    # build only
npm run check    # build, then check WCAG AA colour contrast and internal links
```

There's nothing to `npm install`.

## Deploy (Vercel)

`vercel.json` already sets the build (`node build.mjs`) and the output folder (`dist`), and turns on clean URLs. Connect the repo in Vercel, or run:

```bash
npx vercel --prod
```

Any static host works. Upload `dist/` after `npm run build`.

## Swap the brand

Everything brand-specific is in **`site.config.json`**:

| Key | What it controls |
|---|---|
| `brand.name`, `tagline`, `meaning`, `description`, `logoMark` | Name in the header, footer, page titles, meta tags and copy; the letter in the logo and favicon |
| `contact.*` | Email, business address (also in the home page JSON-LD) and hours (footer, About, enquiry page). No phone number by design. |
| `contact.formEndpoint` | Where the enquiry form posts (for example a Formspree or Basin URL). If it is empty, the form opens the visitor's email app with the enquiry pre-filled. |
| `site.url` | Canonical URLs and the sitemap |
| `palette.*` | Every colour on the site. The build turns these into CSS variables (`terracottaDeep` → `--terracotta-deep`). |
| `fonts.*` | The display, text and mono font stacks, plus which self-hosted font files to preload. Fonts (Instrument Serif, Inter Tight, IBM Plex Mono, from Google Fonts) are self-hosted in `src/assets/fonts`, with their `@font-face` rules in `src/assets/css/fonts.css` inlined into every page. |

To switch to the alternative brand, change `brand.name` to `Paseo Travel` and rewrite `tagline` and `meaning` (for example, "The paseo is the evening stroll through town, when Spain comes out to play."). Then rebuild. The word "sobremesa" also appears in the copy as a Spanish word (the food page, the clock); that's intentional and can stay.

After changing the palette, run `npm run check`. It fails if any text/background pair drops below WCAG AA.

## Edit the content

| File | Content |
|---|---|
| `src/data/regions.mjs` | The nine region guides |
| `src/data/festivals.mjs` | Festivals calendar (month numbers, region slug, notes) |
| `src/data/rail.mjs` | Cities, train links with rough times, ready-made journeys |
| `src/data/clock.mjs` | The Spanish clock: daily blocks per lane, plus hourly tips |
| `src/data/content.mjs` | Food & wine, when to go, stays (placeholders), journal posts |
| `src/data/photos.json` | Photos: Unsplash URL, alt text, caption, source |
| `src/data/legal.mjs` | Privacy Policy, Booking Terms and Cookie Policy (`/privacy/`, `/terms/`, `/cookies/`) |
| `build.mjs` | Page templates and layout |
| `src/assets/css/site.css` | Styles (mobile-first) |
| `src/assets/js/` | Clock, rail planner, festival filters, enquiry form, nav |

To add a journal post, add an object to `journal` in `content.mjs`. To add a festival, add one to `festivals.mjs`. It appears in the calendar and on its region's page. To add a rail city, add it to `cities` and connect it with at least one entry in `links`.

## Photos

All photos are hotlinked from Unsplash (as Unsplash's API guidelines require) and are not credited on the page (the Unsplash License does not require it); the source of each is kept in `photos.json`. Creative Commons images would need a credit. **We only accept a photo if its Unsplash location tag matches the place it illustrates.**

`scripts/find-photos.mjs` does that filtering. It needs `UNSPLASH_ACCESS_KEY` in the environment and writes candidates to `scripts/photo-candidates.json`. Choose by ID in `scripts/picks.json`, then add the entry (with your own alt text) to `src/data/photos.json`. The demo API key allows 50 requests an hour.

## Languages

The site is in English (default), French, German and Spanish. English pages live at the
normal URLs; `scripts/i18n.mjs` runs after `build.mjs` and writes `/fr/`, `/de/` and `/es/`
copies of every page from the translation files `i18n/fr.json`, `i18n/de.json` and
`i18n/es.json` (each maps an English string to its translation; a sentence with inline
markup is one entry). It also sets `<html lang>`, canonical and hreflang links, writes
per-language copies of the page scripts (clock, rail planner, festivals, enquiry form) and
adds every language to the sitemap. No translation code runs in the browser. The header and
menu carry an EN · FR · DE · ES selector. Strings built in JavaScript are whole-phrase
templates (`'%n nights'`, `'This %m: %l'`) so each language can reorder words and plurals.

After changing any English copy, run `npm run i18n:extract`: it rewrites `i18n/source.json`
and lists anything new in `i18n/missing.<locale>.json`. Add the translations to the locale
files; `npm run check` fails until every string is translated.

## Rules this site follows

- Static, fast and mobile-first. No frameworks. Three self-hosted font families (with `font-display: swap`, the above-the-fold ones preloaded). The hero photo is preloaded. Images use responsive `srcset` and lazy loading.
- Design language: full-bleed photo heroes, a giant wordmark, numbered mono section labels, thin grid rules and index lists. Scroll reveals switch off when the visitor prefers reduced motion.
- WCAG AA contrast (checked by `npm run check`), visible focus styles, skip link, and labelled controls. The clock and planner are keyboard-usable, and the festivals calendar works without JavaScript.
- No invented reviews, press logos or awards. Stay names are labelled as placeholders.
